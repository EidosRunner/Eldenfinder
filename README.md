# Eldenfinder

"May grace guide thee, Tarnished."

Un guide interactif pour localiser rapidement n'importe quel item du jeu Elden Ring — armes, armures, Cendres de guerre (Ash of War), et bien plus encore. Conçu aussi bien pour les débutants qui découvrent les Terres Intermédiaires que pour les joueurs aguerris en quête d'un équipement précis.

🎯 Objectif
Trouver un item dans Elden Ring peut vite devenir une aventure en soi. Ce projet centralise toutes les localisations connues dans une interface simple et rapide, pour que tu passes moins de temps à chercher et plus de temps à jouer.

✨ Fonctionnalités
🔍 Recherche par nom — Tape le nom de l'item et accède instantanément à sa localisation
🗂️ Filtres par catégorie — Navigue facilement entre les armes, armures, ashes of war, talismans, objets clés, etc.
🖼️ Captures d'écran & médias — Des visuels pour t'aider à repérer l'item et son environnement en jeu


🛠️ Stack technique
Technologie Usage HTML / CSS Structure et mise en page JavaScript (Vanilla)Logique de recherche et filtresBase de données (SQL) Stockage des données d'items
